# Third-Party License Notices

This directory stores license texts and notices for bundled third-party source,
IP, and tooling dependencies. It complements root-level `LICENSE`, `NOTICE`,
and `ATTRIBUTIONS.md`.

Do not replace, remove, or rewrite a third-party notice when updating a
dependency. Add the applicable license and attribution material in the same
review as a new bundled component, and preserve upstream license text exactly.

The SKY130 OpenRAM SRAM dependency uses
[`OpenRAM-BSD-3-Clause`](OpenRAM-BSD-3-Clause) and
[`SKY130-OpenRAM-Mixed-NOTICE`](SKY130-OpenRAM-Mixed-NOTICE). Its downloaded
artifact also contains the exact Apache-2.0 SkyWater build-space license.
