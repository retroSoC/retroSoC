# Tiny／Mini IP 框图 RM0486 对照与修改记录

实施基线为 dev `3d75177e`，技术来源为 `d9f27811`。Tiny v0.2 DRAFT
以 ICS55 为主，保留 IHP130 兼容配置。Mini v0.5 DRAFT 覆盖 IHP130
PRODUCT、HP 和实际适用的 MPW 实例。视觉对照使用 PR #289 的 Tiny 455 页、
Mini 828 页 PDF 与 manifest。两册发布配置决定各图适用的产品和实例。

对照使用 [ST RM0486 Rev 4][rm0486]（4669 页）。功能相近表示比较同类
数据流，结构类比表示比较功能分区，另有仅借鉴表达的边界、方向或标注案例。
附图沿用同一 IP 的参考图，适用范围见该附图题名及图注。所有路径由本产品
目录解析到相应实例、端口或模块内逻辑。

## 代表性结果

- **Tiny SRAM** 将 AXI32 数据返回与本地返回按去向标明。主图保留分组、仲裁、
  端口和本地返回，另图展示读返回 FIFO 前的分组选择与 owner。主图跨线 28→10。
- **Mini RCU** 保留对外域时钟和复位，把同步器、域活性检测和时基的局部输入
  移到相邻附图，并按 RTL 纠正为 REF24 分频、LP 域边沿检测后输出 1 MHz CLINT 节拍。
  主图跨线 39→10。Tiny RCU 单独展示 SAFE24 和实际后端选择，
  主图跨线 17→12。
- **Mini DMA** 重排读／写与状态路径，主图跨线 13→11。Tiny DMA 和 SPI
  主图保留现有结构。其控制入口、处理路径和反馈已有分区，均达到跨线阈值。
- **Mini GA2D** 以 DMA2D 的前景、背景和输出组织方式作对照。主图保留本产品
  处理链，DMA FIFO 清除和空状态单列。主图跨线 24→12。
- **Mini NPU** 调整命令、局部缓冲、执行与完成路径的端点和线槽，主图跨线
  19→9。Neural-ART 提供分区参考，技术细节来自 Mini 计算单元和集成配置。

## 逐图结果

页码为 PDF 文件页。几何指标按“基线→本轮”记录，依次为桥形跨线数、最多转折
次数及最短线段（mm）。保留表示图形场景原已符合规范，图号和 PDF 页码仍可由于
重排而变化。修改说明列出典型信号或路径。全部端口、证据、逐线坐标及标签前后值
由正式产物中的 `ip-block-sources.json`、`ip-block-geometry.json` 和
`rm0486-comparison.json` 提供。稳定锚点为 `circuit-<图 ID>`。
